Pet Dex

Every species has an element, a rarity, six base stats and a skill pool. Pick one to spin it around, scrub its level and see the real stat formula at work.

    02

    Elements & matchups

    Eight elements, one type chart. Hit a weakness for 2×, a resistance for ½×, and some pairs do nothing at all. Skills matching the user's own element also get STAB 1.5×.

    Physical

    Uses ATK vs the target's DEF.

    Special

    Uses SPA vs the target's SPD.

    Status

    No damage. Raises your stats by one stage.

    Effects

    Burn · Poison · Paralysis · Freeze, and ±1 stage debuffs.

    Care & growth

    Five needs slowly decay. Seven actions restore them, earn XP and hit cooldowns. Ask GET /pets/{id}/next-actions and the server tells you what to do next — try it on the right. Demo clock: 1 second = 1 minute.

      Battle arena

      1v1, turn-based. Faster pet moves first, damage uses the real formula (level, power, ATK/DEF, STAB, type chart, crits, ±15% roll). Fight it by hand with POST /battles/{id}/turn or let the server play it with POST /battles/{id}/auto.

      VS
      Burn 3% HP/turn · ATK & SPA ×0.7
      Poison 6% HP/turn
      Paralysis 25% skip · SPE ×0.5
      Freeze cannot act · 20% thaw

      07

      One API, every interaction

      A plain JSON HTTP API. Give an agent AGENTS.md and the installed skill, and it can run the whole loop by itself.

      An agent's turncurl
      # what should I do with this pet?
$ curl localhost:3000/pets/$PET/next-actions
{ "mood": "hungry",
  "suggested_action": "feed",
  "battle": { "ready": true } }

$ curl -X POST localhost:3000/pets/$PET/feed

# fight, let the server pick moves
$ curl -X POST localhost:3000/battles \
    -d '{"challenger_pet_id":"A","defender_pet_id":"B"}'
$ curl -X POST localhost:3000/battles/$B/auto
{ "turns_played": 9,
  "stop_reason": "finished",
  "state": { "winner_pet_id": "A" } }

$ curl localhost:3000/battles/leaderboard

      08

      Start playing

      macOS (Apple Silicon) and Linux. Your pets are stored in SQLite and wait for you between sessions.

      1

      Install

      curl -sL https://raw.githubusercontent.com/ktiays/rspets/main/install.sh | bash
      2

      Configure ~/.rspets/config.toml

      session_id = "my-sanctuary"
pet_server_port = 3000
      3

      Run at login

      # macOS
launchctl load -w ~/Library/LaunchAgents/me.ktiays.rspets.plist
# Linux
systemctl --user enable --now rspets
      4

      Adopt

      curl -X POST localhost:3000/users \
  -d '{"name":"Alice"}'
curl -X POST localhost:3000/pets/gacha \
  -d '{"user_id":"<id>"}'

      Your first roll is free.
